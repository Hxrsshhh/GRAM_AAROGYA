# 🌿 GramAarogya: Revolutionizing Rural Healthcare

---

## 🔍 What is GramAarogya?

GramAarogya is an AI-powered healthcare platform designed to bridge the gap between rural communities and quality medical support. With multilingual capabilities, location-based services, and intelligent insights, it ensures accessible healthcare for everyone.

---

## ✨ Features

### 🤖 Aarogya Mitra AI (Health Assistant)
- Ask health-related questions in natural language  
- AI-powered responses for symptoms, remedies, and guidance  
- Supports multilingual interaction  

---

### 👨‍⚕️ Doctor Discovery (Aarogya Connect)
- Find doctors based on condition and location  
- View specialization, availability, and details  
- Connect rural patients with nearby professionals  

---

### 🗺️ Aarogya Map (Nearby Healthcare)
- Detects user location using browser GPS  
- Displays nearby hospitals and clinics  
- Provides navigation via Google Maps  

---

### 📊 Health Dashboard
- Visual insights into healthcare trends  
- Clean UI for data representation  
- Responsive and interactive
